02 //

Custom RR New · v1.3.6

The single home for popular Android custom ROMs and custom recoveries. Curates 18 actively maintained ROMs (LineageOS, crDroid, PixelOS, Project Elixir, Project Infinity X, Evolution X, DerpFest, GrapheneOS, CalyxOS, /e/, and more), 5 recoveries (TWRP, OrangeFox, PBRP, SHRP), and 500+ devices, sourced live from the LineageOS wiki and the PixelOS official_devices repo, refreshed nightly by GitHub Actions. Distributed via Google Play, the Amazon Appstore, F-Droid, and GitHub Releases, with a Root section (Magisk, KernelSU, KernelSU Next, APatch, SukiSU Ultra) and native Windows, macOS, and Linux desktop builds alongside Android. Material 3, dynamic color, zero tracking, no Play Services, GPL-3.0.

Aegis, SRE Guardian

An autonomous incident-response system that monitors cloud infrastructure in real time, diagnoses issues with a three-agent AI pipeline (Monitor, Diagnosis, Remediation), and executes safe SSH-based fixes on remote servers. Streams live metrics over WebSockets, searches past incidents with a ChromaDB vector store, and auto-generates PDF post-mortems. Handles CPU surges, memory pressure, disk I/O, DDoS, and DB bottlenecks with a whitelisted command set, no arbitrary shell input.

Built for the AMD Developer Hackathon 2025 under Track 1: AI Agents & Agentic Workflows. You can demo this system here.
